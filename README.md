# Monkey Keke Dash

Nigerian 3D endless runner — ride your keke from Ariaria Market (Aba) to Lagos Island across all 36 states.

**Play now:** https://chukwuib.github.io/monkey-keke-dash/

Installable as an app (PWA): open the link on your phone and choose **Add to Home Screen** / **Install app**.
Also on Google Play: `com.monkeykeke.dash`.

This repo holds the built web bundle only (generated by `tools_buildweb.cjs`).
